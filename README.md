# Manish Raj — Premium Developer Portfolio

A responsive React + Tailwind CSS portfolio starter with a dark tech / 3D-inspired visual direction.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```
